# DR-0001 Build on C# / ASP.NET Core and host on Azure

Date: Sprint 3 (design) · Status: accepted

**Context:** Atlas needs a typed, maintainable web stack with built-in identity support and simple cloud hosting.

**Decision:** C# on .NET 8 with ASP.NET Core MVC, hosted on Azure App Service, with Azure SQL and Blob Storage later.

**Why:** strong typing, built-in identity for Sprint 6, and first-class deployment to Azure. Recorded in the Sprint 3
Product Design Package, section 14, Decision 1.
